# 来信 · 飞书机器人（云端定时消息 · 多用户版）

把「徐言」这套 AI 定时消息，做成一个跑在云端的飞书机器人：到点自动调 DeepSeek 生成消息，
通过飞书 1:1 私聊发到手机。**一个网站托管多个用户**——每个人一个「认领号 + PIN」，
各自独立的人设、报备、接收人，互不干扰。iPhone / 安卓 / 电脑都能用。

## 组成

- `worker.js`：云端服务（调度 + DeepSeek + 飞书发送 + 配置页 + 用户管理）。
- `wrangler.toml`：部署配置（KV 存储 + 每分钟定时）。
- 配置页：部署后浏览器打开 `https://<你的worker>.workers.dev/` 即可登录。

## 两种机器人模式

- **共享机器人（推荐，最简单）**：只建一个飞书应用，管理员填一次 App ID/Secret + DeepSeek Key。
  所有用户默认复用，机器人给组织里所有人发消息，但每人内容不同（人设/称呼/时差/报备各自独立）。
  发送者名字对所有人都一样（就是那个飞书应用名）。
- **一人一个机器人（可选）**：想让每个人的机器人有不同名字/头像，就为每个朋友建一个飞书应用，
  该朋友在自己配置页「高级」里填自己的 App ID/Secret（不填则用共享的）。

## 一、准备工作（一次性）

1. **飞书**：手机装飞书；电脑浏览器打开 [飞书开放平台](https://open.feishu.cn/) →
   创建「企业自建应用」→ 填名字 → 开启「机器人」能力 → 记下 **App ID / App Secret**。
   - 把需要接收消息的朋友都拉进同一个飞书组织。
   - 在应用「权限管理」里开通：`im:message:send`、`contact:user.id:readonly`（用于按邮箱/手机号找用户）。
   - 在「版本管理与发布」里发布应用，并把**可用范围设为全体成员**。
2. **DeepSeek API Key**。
3. **Cloudflare 账号**：注册 https://dash.cloudflare.com （免费）。

## 二、部署

1. 装命令行工具（已有 Node 则只需一条）：
   ```bash
   npm install -g wrangler
   ```
2. 登录：
   ```bash
   wrangler login
   ```
3. 创建 KV 存储，记下返回的 id：
   ```bash
   wrangler kv namespace create BOT_KV
   ```
   把 `id` 填进 `wrangler.toml`。
4. 部署：
   ```bash
   cd "D:\PARA\1_Projects\裴\feishu-bot"
   wrangler deploy
   ```
   记下返回的 `https://xxx.workers.dev` 地址。

## 三、管理员首次配置

1. 浏览器打开 `https://<你的worker>.workers.dev/admin`。
2. 第一次会提示「设置管理员 PIN」，设一个只有你知道的口令 → 进入。
3. 填 **共享飞书 App ID / App Secret / DeepSeek API Key** → 保存共享凭据。
4. 在「用户管理」里为每个朋友（包括你自己）点「＋ 添加用户」，填**认领号**（如 `xuyan`）和 **PIN**。
   - 如果你之前是单用户版，部署后会自动迁移出一个认领号 `owner` 的用户，在列表里给 `owner`「重置 PIN」设个口令即可找回原来的配置。

## 四、发给朋友

把登录链接发给每个朋友：

```
https://<你的worker>.workers.dev/?u=<认领号>
```

并告诉 TA 认领号和 PIN。TA 打开后：
1. 登录 → 在「接收人」里填**自己飞书账号绑定的邮箱或手机号**（必须填，否则不知道发给谁）。
2. 编辑「身份设定 / 参考事件池 / 报备管理」→ 保存。
3. 点「测试发送」验证能不能收到。

> 接收人必须和机器人**在同一个飞书组织**内，且填的邮箱/手机号要能被查到（就是 TA 飞书账号绑定/登记的那个）。

## 五、验证

- 每个用户在自己的页面点「测试发送」，应能立刻收到一条测试消息。
- 把某个报备的「时间」改成 1~2 分钟后保存，到点飞书应收到消息。
- 随机报备按「时段 + 每天条数 + 最小间隔」自动分布，每个用户独立计算。

> 时间按**北京时间**调度。机器人显示的名字，在飞书开放平台「机器人 → 应用名称/头像」里改。
> 若某用户想用自己的机器人，在 TA 页面「高级」里填自己的 App ID/Secret 即可（不填=共享）。

## 常见问题

- **测试发送提示「查不到该接收人」**：确认接收邮箱/手机号是对方飞书账号绑定/登记的那个，且对方在组织内、应用可用范围包含 TA。
- **收不到定时消息**：先看「测试发送」能否成功；定时任务每分钟跑一次，固定时间报备在 `时间` 那一分钟整点触发，随机报备落在「时段」内。
- **忘了管理员 PIN / 用户 PIN**：管理员 PIN 忘了可删 KV 里 `system` 键重设（会丢失共享凭据）；用户 PIN 忘了在管理员页「重置 PIN」。
